# pv-exec-direnv

quiet direnv for zsh, pv_exec style: log popview, package box, auto-retract.

## deps

- zsh
- direnv
- nix (optional, flake package listing)

## zinit

```zsh
zinit ice wait"1" lucid depth=1
zinit light Wateir/pv-exec-direnv
```
